1) Summary ng Topics

1. Variables at Data Types

Ginagamit ang variables para mag-store ng value. Ang data type ay nagsasabi ng klase ng data na maaaring lamanin ng variable tulad ng integers, strings, booleans, at floats.

2. Operators

Ang arithmetic, comparison, at logical operators ay ginagamit para gumawa ng calculations at mag-evaluate ng conditions. Mahalaga ito para sa paggawa ng logic sa code.

3. Control Structures

Kasama dito ang if, else, switch, at loops. Tinutukoy nito kung paano magdecide at mag-ulit ang program batay sa mga kondisyon at requirements.

4. Functions

Ang function ay block ng code na may specific purpose. Pinapadali nito ang pag-repeat ng logic, mas organized ang program, at mas madali itong maintain.

5. Arrays at Lists

Ginagamit ang arrays para mag-collect ng maraming values sa iisang variable. Madalas itong ginagamit para sa data handling at processing.

6. Input / Output

Ang input ay kinukuha mula sa user o file, habang ang output ay ipinapakita sa screen o sinusulat sa file. Ito ang communication ng program sa user.

7. OOP (Object-Oriented Programming)

Ang OOP ay ginagamit para i-model ang code sa pamamagitan ng mga object na may mga attributes at methods. Pinapadali nito ang scalability at code organization.

8. Data Structures

Ang data structures ay tumutukoy sa paraan ng pag-organize at pag-store ng data. Kasama rito ang arrays, stacks, queues, linked lists, at trees.

Detailed Explanation (Taglish)

In programming, each code line acts like a set of instructions given to the computer. When we write code, we are not just typing words; we are defining a sequence of commands that the system must follow. For example, if we want to compute an average, we need input values, a formula, and an output result. When the logic is structured properly, the program can solve the problem accurately. If the code structure is weak or disorganized, the output may become incorrect or difficult to interpret.

A programming language has syntax, which is similar to the grammar of code. If punctuation is incorrect, a semicolon is missing, or the syntax is invalid, the program may fail to run properly. This is why proper syntax is important: it ensures that the computer correctly understands the instructions being provided.

Aside from syntax, logic is equally important. Even if there are no syntax errors, a flawed algorithm can still produce the wrong result. Effective coding combines correct syntax, sound logic, and a well-organized structure. One of the most important concepts is the function, which is a reusable block of code that can be called multiple times in different parts of the program. This improves efficiency and makes the code easier to read and maintain.

2) Reviewer ng Enumeration at Definition

Enumeration

Enumeration refers to a list of related items organized in a specific order or group. In programming, it is commonly used to represent choices, categories, or possible values. Examples include the days of the week, menu options, or status values.

  1. Items that are logically related to one another
  2. Used to organize data in a structured way
  3. Can be listed systematically for easier reading and review
  4. Helps improve clarity and logic in coding

Definition

A definition is the precise meaning or description of a term. For example, a variable is a storage location used to hold data, a function is a reusable block of code, and syntax is the set of rules that must be followed for a program to work correctly. In short, definitions provide clarity and context for each programming concept.

Advanced Concepts

Beyond the basics, programming also includes OOP, which organizes code into classes and objects. This is useful when building larger systems because it promotes modularity, reusability, and maintainability. Data structures, on the other hand, determine how information is arranged and processed for efficient access and retrieval.

  • OOP - organizes code using objects, classes, inheritance, and encapsulation.
  • Data Structures - structures such as arrays, stacks, queues, linked lists, and trees.
  • Efficiency - choosing the correct structure improves speed and memory usage.

3) Reviewer ng Syntax Code

Example 1: Variable and Condition

int age = 18;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

What is its purpose? This code is used to determine whether a person is considered an adult or a minor. The program displays the appropriate output based on the condition.

Function of each part:

  • int age = 18; - declares a variable with an integer value.
  • if (age >= 18) - checks whether the condition is true.
  • { ... } - defines the block of code that executes when the condition is true.
  • else - executes when the condition evaluates to false.
  • System.out.println - prints the result to the screen.

Why is it important? Variables and conditional statements make the program dynamic and interactive. Software can make decisions based on user input or data values.

Example 2: Function

public static int addNumbers(int a, int b) {
    int sum = a + b;
    return sum;
}

System.out.println(addNumbers(5, 7));

What is its purpose? This is used to encapsulate the logic of addition in a single function, reducing repeated code and improving efficiency.

Function of each part:

  • public static - defines the method access level and static behavior.
  • int addNumbers(int a, int b) - defines the function and its two parameters.
  • return sum; - passes the computed value back to the calling code.
  • addNumbers(5, 7) - calls the function and provides the input values.

Why is it important? Functions improve reusability, maintainability, and organization. When a project grows larger, modular code becomes much easier to manage and debug.

Example 3: Loop

for (int i = 1; i <= 5; i++) {
    System.out.println("Number: " + i);
}

What is its purpose? This repeats a statement as long as the condition remains true. It is commonly used for processing lists and handling repetitive tasks efficiently.

Function of each part:

  • for - starts a loop.
  • int i = 1 - initializes the starting value.
  • i <= 5 - defines the condition for continuing execution.
  • i++ - increments the value after each iteration.

Why is it important? Many tasks are repetitive. Instead of writing five separate lines, a single loop can automate the process and reduce complexity.
